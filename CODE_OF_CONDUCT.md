# Contributor Covenant Code of Conduct — RASA-X-MACHINA · tianxiaOS

**RASA-X-MACHINA** is dedicated to providing a technical, rigorous, and harassment-free collaboration environment for all contributors and reviewers across **`tianxiaOS`** and companion projects regardless of background or geography.

## Expected Behavior
- Ground technical discussions in reproducible benchmarks, formal specifications, and verifiable code.
- Respect contributor privacy (`GDPR++`), security boundaries, and responsible disclosure norms.

## Reporting
Report violations confidentially via [https://rasaxmachina.com/collins#encrypted-dispatch](https://rasaxmachina.com/collins#encrypted-dispatch).
